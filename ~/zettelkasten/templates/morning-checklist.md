# 🌅 Morning Zettelkasten Routine

*A daily workflow to maintain and grow your knowledge garden*

## ☀️ Daily Startup (5-10 minutes)

### 📖 Review & Connect
- [ ] Open yesterday's daily note: `<leader>zd` 
- [ ] Scan for incomplete tasks and important insights
- [ ] Check for [[unlinked notes]] that could be connected
- [ ] Review any loose thoughts that need processing

### 📝 Today's Daily Note  
- [ ] Create today's daily note: `<leader>zd`
- [ ] Set 3 main focus areas for the day
- [ ] Brain dump any immediate thoughts or ideas
- [ ] Add links to relevant ongoing projects: [[Project Name]]

## 🔍 Knowledge Maintenance (10-15 minutes)

### 🧹 Housekeeping
- [ ] Find orphaned notes: `<leader>zf` → search for isolated content
- [ ] Strengthen weak connections by adding more [[cross-links]]
- [ ] Tag review: ensure consistent #tagging across related notes
- [ ] Archive or merge duplicate/outdated notes

### 🌱 Growth Activities
- [ ] **Idea Capture**: Add any overnight insights to relevant notes
- [ ] **Connection Discovery**: Look for patterns between recent notes
- [ ] **Weekly Theme**: Identify what topic clusters are emerging
- [ ] **Question Generation**: Note down questions to research later

## 🎯 Planning Integration (5 minutes)

### 📋 Task Alignment
- [ ] Review project notes for today's actions
- [ ] Update task status: `<leader>zt` to toggle todos
- [ ] Link today's work to relevant knowledge: [[Background Research]]
- [ ] Set learning intentions for the day

### 📚 Learning Queue
- [ ] Check [[Reading List]] and [[Research Queue]]
- [ ] Identify 1-2 concepts to explore today
- [ ] Plan time for note processing from recent learning

## 💭 Morning Reflection Prompts

*Pick 1-2 to journal about in today's daily note:*

- What connection between ideas surprised me recently?
- What question am I most curious about right now?
- Which note deserves more attention and development?
- What pattern am I starting to notice across my notes?
- How has my thinking evolved on [[topic]] lately?
